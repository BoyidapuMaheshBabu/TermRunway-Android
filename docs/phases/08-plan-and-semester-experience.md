# Phase 08 — Plan and Semester Experience

## Status

**Completed — developer accepted**

## Objective

Develop and refine TermRunway's planning experience for students managing money across a semester or defined period.

## Intended Scope

- plan-period setup
- expected income and expenses
- time-aware planning
- money-first guidance
- connection between planned information and actual transaction activity
- clear handling of remaining money and remaining time

## Product Intent

Planning should answer **"What will happen?"** while remaining connected to what actually happens in Daily Tracking.

## Completed Work

Phase 08 was implemented, refined, validated, and merged into the Android main baseline.

Key outcomes:

- refined plan-period setup and planning flow
- expected income and planned expense handling
- Active Plan experience
- remaining money and remaining days context
- Safe to Spend Today guidance
- planned-versus-actual financial understanding
- final 2×2 Plan dashboard financial summary:
  - Income — actual / expected
  - Expenses — actual / planned
  - Safe to Spend Today
  - Remaining Days
- preserved the connection between planning and the shared transaction foundation
